# GrammyGuesser App Prototype

<b> GrammyGuesser</b> is a mobile application prototype designed through an iterative, user-centered process to explore how people predict and discuss Grammy Award winners.

This repository contains the code (inside the "grammyGuesser" folder) along with the design evolution of the GrammyGuesser - from early concept exploration to refined interaction and interface decisions. The poster below walks through key iterations, including problem framing, feature refinement, visual design choices, and usability-driven improvements made throughout development.
