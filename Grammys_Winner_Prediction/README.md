# GrammyGuesser App Prototype

<b> GrammyGuesser</b> is a mobile application prototype designed through an iterative, user-centered process to explore how people predict and discuss Grammy Award winners.

This repository contains the code (inside the "grammyGuesser" folder) along with the design evolution of the GrammyGuesser - from early concept exploration to refined interaction and interface decisions. The <a href="./1_GrammyGuesser_Poster.pdf">"1_GrammyGuesser_Poster.pdf"</a> file showcases a walkthrough of the key iterations, including problem framing, feature refinement, visual design choices, and usability-driven improvements made throughout the app development.

For a deeper look at the design process - covering ideation, prototyping, testing, and iteration - please refer to the
<a href="./2_GrammyGuesser_App_Prototype_Presentation.pdf">"2_GrammyGuesser_App_Prototype_Presentation.pdf"</a> file.
